Multi-version JDK & Maven Manager

让 JDK 与 Maven
随取随用

jm 是一个用 Go 编写的多版本 JDK / Maven 管理工具。搜索、安装、切换、卸载，全部一条命令搞定；支持 Temurin、Zulu、OpenJDK 三大发行版与 Apache Maven，附带 Windows 图形界面。

Capabilities

为什么选 jm

01 / 04

01

多发行版并存

Temurin、Zulu、OpenJDK 与 Maven 同仓共存，--distro 一个标志自由切换来源，告别手动解压与环境变量打架。

02

镜像加速下载

内置 TUNA Adoptium 镜像与华为云 Maven 镜像，国内网络直连下载大体积 JDK 也不再漫长，失败自动回退官方源。

03

校验与安全解压

所有安装包强制 SHA256/512 校验，缺失校验和直接拒绝；解压带 zip bomb 与符号链接防护，装得放心。

04

环境自动配置

Windows 写入注册表 JAVA_HOME / PATH，Unix 维护 shell rc 块；jm use 17 即切，卸载自动回退到剩余最高版本。

05

项目级版本固定

仓库里放一个 .jvmtoolrc（jdk=17 / maven=3.9），进入目录即锁定团队一致的工具链版本。

06

体检与自更新

jm doctor 检查环境与代理配置，jm update 一键升级到最新版；断点续传 + 重试，弱网也能装完。

In Practice

常用命令

02 / 04
zsh — jm
$ jm jdk search 17 --distro zulu      # 在 Zulu 中搜索 JDK 17
$ jm jdk install 17.0.20                # 下载并安装（镜像优先）
$ jm jdk use 17                         # 切换当前版本
$ jm maven install 3.9.11 && jm maven use 3.9
$ jm status                             # 查看已安装与当前版本
$ jm jdk import /usr/lib/jvm/java-21    # 收编系统里已有的 JDK
$ jm doctor                             # 环境与代理体检
